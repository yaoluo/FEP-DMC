# FEP-DMC
first-principles electron-phonon diagrammatic Monte Carlo simulation package. 

## Data sets 
All the raw data and figure generating processes are included in `dataset/` for all the figures in our paper. 

## Demo
We provide a minimal demostration on calculating the polaron formation energy in electrons of LiF in `example\`
To reproduce the calculations, please follow example/README.md.
